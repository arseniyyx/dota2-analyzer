How to install the grid in Dota 2

  1. Close Dota 2 and download hero_grid_config.json.
  2. Put it into Steam\userdata\<Friend ID>\570\remote\cfg\ replacing the old one.
  3. Already have your own grids? Load your current file with “Add to my file…”: the new grid is added and the old ones stay.
  4. Start Dota: the grid shows up in hero pick and on the Heroes page.
