Моды для Dota 2: D2A Mods

Бесплатная программа для Windows: 27 своих модов и больше 200 модов сообщества. Больше FPS без погоды и лишних эффектов, без травы и кустов, тёмный ландшафт, контрастное ХП крипов, шрифты, курсоры, фоны меню и перекраска героев. Отмечаешь моды, нажимаешь «Установить» — программа сама находит Dota.

Скачать D2A Mods 1.9.0

Только визуальные и звуковые моды без преимущества в игре и без вмешательства в процесс Dota. Файлы игры не меняются: моды ставятся отдельными файлами и удаляются одной кнопкой. Valve официально моды не поддерживает.

Оптимизация

  • ☂ Без погоды FPS

    Дождь, снег, пепел, листья и другая погода из предметов. Самая заметная прибавка FPS в драках.

  • ✦ Без фоновых эффектов карты FPS

    Светлячки, пыль, блики и капли на ландшафтах. На игру не влияет.

  • ❦ Без птиц и насекомых FPS

    Летучие мыши, птицы и мошкара над картой.

  • ✧ Без свечения косметики FPS

    Постоянные эффекты на предметах героев: огонь, искры, дымка. Способности и их эффекты остаются.

  • ✉ Без эффектов курьеров FPS

    Огонь, свечение и следы у курьеров из сокровищниц. Сами курьеры остаются.

  • ◎ Без эмблем FPS

    Ауры эмблем из ивентов вокруг героев.

  • ◉ Без эффектов скинов вардов FPS

    Свечение и частицы у вардов из сокровищниц. Сами варды видны как обычно.

  • ▣ Без обломков зданий FPS

    Взрывы и обломки, когда разрушаются башни и статуи.

  • ✺ Без праздничного декора FPS

    Конфетти, фейерверки и украшения фонтанов из ивентов.

  • ⌂ Без эффектов зданий и базы FPS

    Свечение и дым зданий, лава и разрушения на базах, аванпосты, фонтаны, статуи, эмблемы. Глиф, щит Торментора и снаряды башен остаются. По списку из Minify.

  • ➶ Простые атаки дальнего боя FPS

    Меньше свечения и искр у автоатак героев дальнего боя. Снаряд виден как обычно. По списку из Minify.

  • ✷ Простые заклинания и предметы FPS

    Убирает лишнее свечение, искры и дым у стандартных заклинаний и предметов, сами эффекты остаются. Меньше нагрузки в драках. По списку из Minify.

  • ♪ Без фоновых звуков карты Звук

    Фон карты и звуки животных. Игровые звуки остаются: рога, аванпосты, Торментор, Twin Gates, деревья, день и ночь.

Кастомизация

  • ⊘ Без звуков чат-колеса Звук

    Глушит саундборд: «Ой-ой-ой», «Ехехе» и прочие звуки, которыми спамят в чате.

  • ≈ Без реки Вид

    Обычная тёмная вода вместо реки, без брызг, водопадов и звуков шагов по воде. Краски для реки тоже не видны. По моду из Minify.

  • ✎ Без спреев Вид

    Граффити, которые игроки рисуют на карте, не показываются. По списку из Minify.

  • ♫ Без комментатора Звук

    Стандартный комментатор молчит: начало игры, руны, Рошан и прочее. По списку из Minify.

  • ✕ Без реплик серий убийств Звук

    Без «Rampage!», «Godlike!» и других выкриков за серии убийств. По списку из Minify.

  • ☹ Без звуков насмешек Звук

    Глушит звуки насмешек героев. Сами насмешки видны. По списку из Minify.

  • ☊ Без голосовых реплик героев Звук

    Герои не разговаривают во время игры: реплики при движении, атаке, покупках. Заодно молчит чат-колесо. По списку из Minify.

  • ✋ Без эффектов «Дай пять» Вид

    Вспышки и картинки над героями при «Дай пять».

  • ☺ Без эффектов насмешек Вид

    Частицы от насмешек героев. Сама анимация остаётся.

  • ◐ Тёмный ландшафт (Minify) Вид

    Серые тайлы карты, линии тумана вместо дымки, тёмная вода. Нужен стандартный ландшафт. Вместо шейдеров тумана и ландшафтов D2PFX. Мод из Minify.

  • ❀ Без кустов и декора (Minify) Вид

    Убирает кусты, цветы, камни и мелкий декор на земле, остаются только тайлы. Деревья не трогает. Нужен стандартный ландшафт. Мод из Minify.

  • ▰ Контрастное ХП крипов Вид

    Недостающее ХП у крипов чёрное, а оставшееся ярче, поэтому сколько осталось, видно сразу. Цвет команды игра накладывает сама, меняется только яркость.

  • ✦ Кастомизация героев Вид

    Свои цвета для любого героя и его частей, плюс иконки способностей. Красишь в 3D-редакторе, видишь только ты.

  • Aa Английский интерфейс Вид

    Для тех, кто играет на английском: поставь в параметрах запуска -language dutch, и моды заработают, а текст останется английским. С русской озвучкой тоже работает.

Как поставить моды

  1. Скачай D2AMods.exe и закрой Dota 2.
  2. Запусти программу. Если Windows предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
  3. Отметь моды и нажми «Установить».
  4. После обновления Dota, если моды пропали, нажми «Установить» ещё раз. Вернуть всё как было: «Удалить все моды».
